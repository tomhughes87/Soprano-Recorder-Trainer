# The Lincolnshire Poacher reference

- [Folkinfo / John Chambers ABC transcription](https://abcnotation.com/tunePage?a=www.joe-offer.com%2Ffolkinfo%2Fsongs%2Fabc%2F124%2F0000)

The implementation uses the complete 6/8 Folkinfo melody and raises it one semitone, from C to D-flat, so its B3–C5 range fits the supported C4–D5 notes.
