# Zelda song references

Each child folder owns one playable input sequence and any longer continuation migrated from the original flat `zeldaShort.ts` and `zeldaLong.ts` catalogues. Its `reference.md` now links to the documented in-game song and the Ocarina of Time song guide.

The short button inputs establish pitch order, not scored duration. `rhythmVerified` therefore remains false until a permitted score, MIDI, or MusicXML reference establishes exact timing. Migrated long continuations likewise remain unverified.
