# Merrily We Roll Along — reference

- Reference: [Singing Bell — Merrily We Roll Along](https://www.singing-bell.com/merrily-we-roll-along-mp3/)
- The teaching arrangement is in 4/4 and uses only B, A and G.
- This tune shares its melody with the commonly taught version of “Mary Had a Little Lamb”; it is kept as a separate exercise because both titles were requested.
