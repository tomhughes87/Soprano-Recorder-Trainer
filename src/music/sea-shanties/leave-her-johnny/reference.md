# Leave Her, Johnny reference

- [Dupont Music Circle / BBC Singing Together transcription](https://abcnotation.com/tunePage?a=dmc.lizmilner.com%2Fviewabc.vbhtml%3Ffile%3DLeave+Her.+Johnny.+Leave+Her%2F0002)

The implementation uses the verse melody and transposes it down a perfect fifth, mapping the G4–G5 source into C4–C5. The terminal one-beat vocal breath is omitted because silent events are not yet part of the trainer event model.
